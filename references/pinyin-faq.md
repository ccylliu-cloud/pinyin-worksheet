# Agent 拼音核对边界

一次识图提取后逐字对照原图，核计总词数；形近字不能由拼音反推猜测。
Agent 按完整词语语境注音，多音字不能套单字最高频读音。
一字一音节，轻声不标调；标调有a先a，其次o/e，i/u并列取后者。
n/l 后的ü保留两点，j/q/x/y后写u。词义不足以定音时向用户确认。
本练习不支持儿化合并音节与音节化m/n；遇到这种输入先与用户协商表达。

Python 不建立或查询读音库，不默认多Agent复核。校验通过只代表格式、标调及版式通过，
不代表语境定音正确；也不声称穷举所有合法音节组合。
无声调被保留并报告 warning，Agent 必须分辨轻声还是漏调。
示例52词仅用于程序回归，不得替代新任务的逐字核对。
