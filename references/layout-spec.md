# V2 版式规格

A4 210×297mm；上下左右页边距 12/10/10/10mm，版心 190×275mm。
词组宽为字数×15mm；词组间距4mm，以189mm为换行阈值；词序不变，不拆词。
页眉9mm，拼音区6mm，拼音至格1mm，字格15mm，行间2.2mm。
每页内容高 = 9 + 行数×24.2 - 2.2mm。11行=273mm，不能放第12行。
由 Python 以整行分配页面，最多11行/页；不交给浏览器流式分页。

52词基线11行，组数5/5/5/4/5/5/5/5/5/5/3，一页。
104词为原表顺序重复两遍；贪心排布跨越重复处，不假定每52词分页。

ReportLab 使用 pt，转换比为72/25.4 pt/mm。外框15mm，内部边线只画一次，
中心线为浅灰虚线。物理打印选A4、实际大小100%；不得为页数缩格。
15mm 是本项目指定版式，不将未核验的旧版行业标准说法当作依据。
